# Comparative Results

This directory contains the updated comparative model outputs for the human activity recognition datasets used in this project.

## Datasets

- `uci-har/`: UCI Human Activity Recognition results and ablation study outputs.
- `mhealth/`: MHEALTH model comparison results.
- `opportunity/`: Opportunity dataset model comparison results.

## Folder Layout

- `notebooks/`: Jupyter notebooks used for training, evaluation, and ablation analysis.
- `results/`: Metrics, summaries, confusion matrices, ROC curves, class distributions, and visualization plots.
- `models/`: Saved trained model artifacts.
- `ablation/`: Ablation study metrics and plots, where applicable.

Large raw dataset archives are intentionally not included here. The result archives were extracted so that metrics and plots can be browsed directly on GitHub.
